# Source Ledger — External Evidence Provenance

> ### **PROVENANCE IS EVIDENTIARY INFRASTRUCTURE, NOT ADVOCACY. SOURCES ARE PRESERVED EQUALLY FOR FINDINGS THAT CUT *AGAINST* THE WORKING HYPOTHESIS.**

**Opened 2026-08-19, at Stage 40½, when the author asked the question that exposed the gap: *"are we independently marking these sources also for Claude, or did we forget that one little detail?"***

> ### **THE HONEST ANSWER WAS: CITATION PRESERVATION HAD BEEN HAPPENING; EXPLICIT SOURCE-PROVENANCE MANAGEMENT HAD NOT BEEN FORMALIZED. This file closes that gap — caught immediately before the dating / Nero / 666 investigation makes external evidence far more load-bearing than it has been for the first 40 stages.**

---

## 🔑 THE GOVERNING RULE

> ### **DO NOT TREAT A CHATGPT OR CLAUDE STATEMENT AS THE SOURCE. THE UNDERLYING SOURCE IS THE SOURCE.**
>
> **"Tacitus says…" must ultimately point to *Annals* 15.44 — not to the tranche that reported it.**
>
> ### **A SOURCE CITED BY A MODEL BUT NOT INDEPENDENTLY OPENED REMAINS *REPORTED — NOT VERIFIED* UNTIL VERIFIED.**

---

## 📐 The three provenance layers

**These are NOT interchangeable records, and the project preserves all three.**

| Layer | Question | Lives in |
|---|---|---|
| **1. Biblical provenance** | *Where does Scripture actually say this?* | [[05-scripture-index]] + each stage's `localization` field |
| **2. External evidentiary provenance** | *What manuscript, historian, archaeological find, lexicon or scholarly work supports this?* | **THIS FILE** |
| **3. Research-process provenance** | *Where in the Mars ↔ ChatGPT ↔ Claude investigation did this idea, correction or hypothesis originate and evolve?* | stage files + [[00a-narrative-spine]] |

### Worked example — why layer 3 is not redundant

**Finding: Revelation 12:12's "short time" ≠ necessarily Revelation 20:3's "little time."**

| Layer | |
|---|---|
| **Biblical** | Revelation 12:12 · Revelation 20:3 |
| **Lexical** | ὀλίγον καιρόν *oligon kairon* vs μικρὸν χρόνον *mikron chronon* ⚠️ *Greek NOT retrieved — q162* |
| **Research-process** | **THE AUTHOR challenged an apparent conflation during Stage 39**, which is what caused the two-period hypothesis to be preserved explicitly rather than collapsed |

> ### **THE THIRD ROW IS UNUSUAL AND VALUABLE: IT RECORDS THAT A HUMAN OBJECTION, NOT A TEXT, PRODUCED THE DISTINCTION. That belongs in an unabridged research edition** *(ADR-0010)*.

## 🏷️ Verification states

| State | Meaning |
|---|---|
| ✅ **VERIFIED** | independently opened and read this session; wording preserved |
| 🟡 **PARTIALLY VERIFIED** | opened, but returned incomplete, summarized, or in translation only where the original matters |
| ⚠️ **REPORTED — NOT VERIFIED** | asserted in a tranche or by a model; **not** independently opened |
| ❌ **VERIFICATION FAILED** | attempted and could not be reached — **name which rungs of the source ladder were tried and how each failed** |
| 🔖 **SOURCE-BACKFILL** | claim in use from Stages 1–40½ whose provenance still needs reconstruction |

---

## 📚 Evidence tiers

| Tier | |
|---|---|
| **PRIMARY** | contemporary or near-contemporary documentary/manuscript evidence |
| **EARLY SECONDARY** | early testimony within living memory of the events |
| **LATER SECONDARY** | later historians preserving earlier traditions — **identify the earlier source claimed wherever possible** |
| **MODERN SCHOLARLY** | contemporary scholarship; useful for orientation, never a substitute for the underlying evidence |

## 🔖 SOURCE-BACKFILL REGISTER — Stages 1–40½

> ### 🛑 **DO NOT STOP THE SEQUENTIAL INVESTIGATION TO COMPREHENSIVELY BACKFILL EVERY SOURCE NOW. The original research threads still exist; a 40-stage detour would cost more than it recovers at this point.**

### The backfill protocol

> **1. WHEN AN OLDER CLAIM BECOMES CONSEQUENTIAL TO A LATER ARGUMENT, VERIFY AND SOURCE IT AT THAT POINT.**
>
> **2. BEFORE MANUSCRIPT PUBLICATION, PERFORM A COMPLETE BACKWARD SOURCE AUDIT FROM STAGE 1 ONWARD, so every externally dependent material claim can be traced to its underlying evidence.**
>
> ### 3. ❗❗ **NEVER SILENTLY UPGRADE AN OLDER UNSOURCED ASSERTION INTO A SOURCED FACT MERELY BECAUSE IT HAS BEEN REPEATED ACROSS MULTIPLE STAGES.**

**That third rule is the dangerous one. Repetition across stages FEELS like corroboration and is not. A claim restated in five files is still one unsourced claim.**
