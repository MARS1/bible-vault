# Spanish Register Standard

> ## **TARGET: *español latinoamericano internacional, culto pero accesible.* Tuteo, contenido, pronoun usually implicit.**

---

## 1. What this pass is, and what it is not

| ✅ **It removes** | 🛑 **It does NOT remove** |
|---|---|
| Distinctly **Rioplatense / regional** vocabulary | Ordinary conversational Spanish |
| Constructions that read **awkwardly outside** one country | *o sea*, direct first-person narration, restrained tuteo, conversational rhythm |
| **English syntax** still audible under the Spanish | The author's direct, self-critical voice |

> ### 🛑 **THIS IS NOT AN ACADEMIC-LANGUAGE SANITIZATION PASS. Flattening the prose into neutral scholarly Spanish would cost more than the regionalisms do.**
>
> ### 🛑 **RVR1960 WORDING IS NEVER TOUCHED.** Biblical quotations stay verbatim, *vosotros* and all. The checker skips every line beginning with `>` for exactly this reason.

---

## 2. The list *(grows with every review)*

| Regional / awkward | International | Added |
|---|---|---|
| `acá` | **`aquí`** | 2026-09-10 |
| `demasiado chico` | **`demasiado pequeño`** | 2026-09-10 |
| `de manera despareja` | **`no … por igual`** / `de manera desigual` | 2026-09-10 |
| `darse vuelta` | **`volverse`** | 2026-09-10 |
| `está por decir` | **`está a punto de decir`** | 2026-09-10 |
| `me apretaba` | **`me presionaba`** | 2026-09-10 |
| `se quedaron con el lugar` | **`se apoderaron del lugar`** | 2026-09-10 |
| `plata` *(money)* · `pibe` · `laburo` · `che` · voseo | ❗ **never** | 2026-09-10 |

**⚠️ AWKWARD CONSTRUCTIONS ARE REWRITTEN, NOT WORD-SWAPPED.** Recorded so the pattern is recognizable, not so the phrase is banned:

> ❌ *"si a un creyente que recibió algo verdadero **le queda libre callarlo como política permanente**"*
> ✅ *"si un creyente que ha recibido algo verdadero **puede decidir, como postura permanente, guardar silencio al respecto**"*

---

## 3. The per-Part bilingual integrity check

> ### **RUN AT THE END OF EVERY SPANISH PART, BEFORE ITS MILESTONE SNAPSHOT.**

| | Check | Passing looks like |
|---|---|---|
| **1** | **Provenance survives** | who advanced which position, unchanged from EN |
| **2** | **Evidence strength survives** | `EXIGE / APOYA / NO ESTABLECE` match EN's `REQUIRES / SUPPORTS / DOES NOT ESTABLISH` |
| **3** | **Asymmetries survive** | where EN refuses a tidy symmetry, ES refuses it too |
| **4** | **Scripture is RVR1960** | never English rendered into Spanish |
| **5** | **Spanish-only notes present** | every open SYNC entry that needs one has one |
| **6** | **Register** | checker reports zero |
| **7** | **`vosotros` only inside quotations** | zero prose hits |
| **8** | **Components match** | same semantic divs, same places |

**📐 AND THE ASYMMETRY THAT MATTERS: a theological or evidentiary divergence is a DEFECT and gets corrected in both editions. A prose divergence is EXPECTED — these are sibling editions, and identical sentences would mean the Spanish was translated rather than written.**
