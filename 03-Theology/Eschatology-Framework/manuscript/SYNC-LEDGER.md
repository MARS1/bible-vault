# Bilingual Synchronization Ledger

> ### **WHAT GOES IN HERE: a translation witness raising a materially different issue · one edition exposing a correction that affects the underlying argument · original-language evidence needing different explanation in each language · a revision to one edition that may require revision to the other.**

---

## SYNC-001 — Revelation 20:10, RVR1960 *estaban*

| | |
|---|---|
| **Status** | ❗ **OPEN. Spanish-specific TEXTUAL NOTE required. English edition must mention the Greek ellipsis wherever 20:10 is load-bearing.** |
| **Greek** | ✅ **No corresponding finite verb. No ἤδη.** *(q429)* |
| **RVR1960** | **"donde ESTABAN la bestia y el falso profeta"** — an imperfect indicative |
| **The problem** | **A Spanish reader is handed the "[already] are" reading this archive explicitly refused the English tranche.** |
| **The rule** | 🛑 **RVR60's *estaban* is SUPPLIED TRANSLATION SYNTAX. It may NOT be promoted into Greek grammatical evidence.** |
| **Affects the argument?** | **No. The Revelation 19 → 20 literary-sequence finding is untouched.** |
| **Where** | q439 · [[09-manuscript-integrity-audit]] §18 · manuscript Part VI |

## SYNC-002 — Romans 9:4, *el pacto* singular

| | |
|---|---|
| **Status** | ❗ **OPEN. Spanish TEXTUAL NOTE written into ES Chapter 5. English needs no equivalent note.** |
| **RVR1960** | **"de los cuales son la adopción, la gloria, EL PACTO, la promulgación de la ley"** — ***singular*** |
| **English witnesses** | **plural, "the covenants"** |
| **Behind it** | ⚠️ **A known Greek variant, αἱ διαθῆκαι against ἡ διαθήκη. NOT ADJUDICATED HERE and NOT NEEDED — flagged for verification, not resolved.** |
| **Affects the argument?** | **No. Chapter 5's point rests on what is listed as Israel's and on Romans 11:1's μὴ γένοιτο, not on the number of the noun.** |
| **Noted in passing** | ✅ **RVR1960 itself reads PLURAL at Ephesians 2:12, "ajenos a los pactos de la promesa." The Spanish edition is not internally uniform, and the note says so.** |
| **Found by** | **Drafting ES Part I. Nobody was looking for it.** |

## SYNC-003 — *"Predicar no es lo mío"* is not a foreign phrase in Spanish

| | |
|---|---|
| **Status** | ✅ **RESOLVED BY DESIGN. No correction needed in either edition.** |
| **English edition** | Quotes the phrase **in Spanish and says so**, because the fact that the author said it in Spanish is part of the texture. |
| **Spanish edition** | **Simply says it.** ❗ **The English chapter's aside about the phrase being Spanish would be nonsense in Spanish and is correctly absent.** |
| **Why it is logged** | 📐 **It is the clearest small proof that these are SIBLING EDITIONS and not a translation: the same sentence needs different framing in each, and neither framing is a defect in the other.** |

> ### 🛑 **STANDING RULES**
>
> ### **① A translation witness is evidence about ***that translation***. It is never evidence about the Greek or the Hebrew.**
> ### **② If Spanish work exposes an evidentiary problem affecting BOTH editions, BOTH canonical editions get corrected. "English is already done" is not an answer.**
> ### **③ A purely Spanish rendering issue gets a Spanish TEXTUAL NOTE and does NOT change English prose.**
> ### **④ Nothing in this ledger may upgrade evidence strength in either direction.**
