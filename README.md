# BIBLE Vault

> Bible study vault — Scripture, theology, commentary, and spiritual growth.

## What This Is

A systematic Bible study vault. Mars studies the Bible systematically, capturing theological insights, character studies, and devotional reflections organized by Testament and topic.

## Structure

| Folder | Contents |
|--------|----------|
| `00-Inbox/` | Quick captures, devotional thoughts |
| `01-Old-Testament/` | Pentateuch, Historical, Wisdom, Prophets |
| `02-New-Testament/` | Gospels, Acts, Epistles, Revelation |
| `03-Theology/` | Doctrine, systematic theology |
| `04-Characters/` | Bible people studies |
| `05-References/` | Cross-references, maps, tools |
| `06-Archive/` | Completed or superseded |

## Getting Started

1. Open in Obsidian: File → Open vault → select this folder
2. Start at HOME.md for navigation
3. Read CLAUDE.md before starting an AI session

## AI Sessions

```bash
cd /Volumes/VM/OBSIDIAN/BIBLE
claude
```
