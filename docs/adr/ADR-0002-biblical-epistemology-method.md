# ADR-0002: Biblical Epistemology as a Foundation Layer

## Terminology
**Biblical Epistemology** — how one comes to know, test, and discern truth within a biblical framework (Scripture, prayer, the Ruach, investigation, discernment, testing, correction) — distinct from the *content* of what's believed.
**Contextual Exegesis** — interpreting a passage by its immediate audience/historical/covenantal context before applying it broadly. Prevents a verse addressed to a specific audience (e.g. the Twelve) from being read as a blank-check promise to every reader in every era.

## Context
The Israel/Gentile commission question exposed a real risk in the existing 4-box structure: a verse could support the "explicit conviction" tier without first passing through *why* it's being read that way. Two opposite errors were both live: erasing Yeshua's Israel-focused earthly ministry to make room for a universal Great Commission, or erasing Paul's explicit Gentile commission to defend an Israel-only reading. The existing 3-tier split (explicit text / inference / speculation, from `00-index.md`'s original governing principle) didn't have a step that forces "who was this addressed to, and does the wider canon support extending it" before a verse counts as settled.

## Decision
Added `00b-biblical-epistemology.md` as a foundation file, read before `01-convictions.md`. It defines the two terms above, a working model (Scripture → Prayer → Ruach → Investigation → Discernment → Testing → Humility → Correction), and a mandatory 7-step test for any passage before it counts as an established conviction: Text → Context → Canonical Context → Covenant/Historical Context → Interpretation → Application → Test. The Israel/Gentile commission question is preserved in that file as the permanent worked example — not because it's uniquely important doctrinally, but because it's the case that proved the method was missing.

## Consequences
- Any future verse being promoted into `01-convictions.md` should be able to show it passed the 7-step test, not just that it supports a conclusion already reached.
- Existing convictions get retrofitted with caveats where the test reveals a gap — e.g. `01-convictions.md` A.13 (Ruach guidance) now notes John 14:26/16:13 were addressed to the Twelve specifically, with the broader-application claim resting on other texts instead.
- The standard for testing a claim is now explicit: not "how do I prove I'm right" but "if I'm wrong, what passage would expose it."
