# ADRs — BIBLE Vault

Decision records for this vault: writing-style conventions, structural choices, and the formal terminology behind informal phrases used along the way. One numbered file per decision — Context, Decision, Consequences, plus a Terminology line whenever an informal term maps to a formal one.

Not code-architecture ADRs — same pattern, applied to a research/writing vault: durable, non-obvious decisions worth being able to find again later, not day-to-day content edits.
